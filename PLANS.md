# Планы

## Правила ведения файла

- Каждый план — отдельный раздел с номером и заголовком: `## N. Название`. Номера идут по порядку и не переиспользуются.
- Выполненные пункты удаляются из плана (факт выполнения пишется в `CHANGELOG.md`). Если в плане не осталось пунктов, удаляется весь раздел.

## 1. Убрать локальные копии глобальных функций

Убрать конструкции вида `local string_match = string.match`, `local util_Compress = util.Compress`, `local hook_Run = hook.Run` во всём коде.

Причины: в обычном коде выигрыша нет, ссылка фиксируется при загрузке и обходит подмены других аддонов (ULX, античиты, профайлеры), шапки файлов съедают лимиты local/upvalue и мешают читать.

Исключение — только горячие пути (цикл обновления акторов, A*, генератор нод, сериализатор `core/sh_net.lua`, отрисовка), и только для того, что реально вызывается в цикле (`math.floor`, `Vector`, `util.TraceLine`, `IsValid`). Нельзя локализовать никогда: `hook.*`, `net.*`, `ents.Create`, `timer.*`.

- [ ] Новый код ядра: `core/sh_cvars.lua`, `core/sh_commands.lua`, `core/sh_util.lua`, `core/sh_tasks.lua`.
- [ ] Старые файлы — при их переписывании на этапах 2–4 (`REWRITE_PLAN.md`), отдельным проходом не трогать.
- [ ] Финальная проверка поиском по `^local \w+_\w+ = \w+\.\w+$` перед этапом 6.
