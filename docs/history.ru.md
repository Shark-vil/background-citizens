# История версий и база документации

Сверено с Git до тега **2.3.0** (`2258b49`) и текущей **2.3.1 dev** (`7459c3c7`, 2026-11-10). В `version.txt` и `bgNPC.VERSION` указана 2.3.1. Между тегом и базой — 48 коммитов. Номер версии не подтверждает публикацию в Workshop.

| GOAP | Завершённые действия (укрытие, подкрепление) продвигают план, а не блокируются; нет бесконечного цикла укрытия; полицейский с арестом заставляет план ждать; выбор реакции не запускает сдачу. Полицейский в меньшинстве уходит в укрытие и вызывает подкрепление, объявляя врагов в розыск; один вооружённый враг подкрепление больше не вызывает. [Мозги](systems/brains.md). |
| Розыск | Как в 1.x, таймер стоит полным, пока жители видят цель, в том числе актора (а не только когда он дерётся); цель в машине видна сквозь корпус машины. Разыскиваемый NPC получает уровень каждые `bgn_wanted_level_up_period` секунд. Разыскиваемый NPC снимается с розыска через 15 с вне поля зрения всех игроков либо дальше половины `bgn_spawn_radius_visibility` (препятствия не учитываются); запрет появления транспорта перед игроком перенесён в `bgn_vehicle_spawn_visibility_radius`. [Розыск](systems/wanted.md), [меню](systems/menu.md). |
| Очистка | Тела актёров без живого зарегистрированного актёра удаляются через 3 с независимо от здоровья (застывшие тела, убитые во сне LOD), в том числе при `bgn_enable 0`. [Мозги](systems/brains.md). |

Исправление в рабочем дереве после этой базы (строка версии 2.4.0, публикация не проверена): дверные сцены используют
только полностью закрытые двери, стук направлен на полотно, а открытие/удаление связанной двери возвращает участников
обычному ИИ. Админская команда спавна тоже использует поиск позиции у двери. См. [сценические сцены](systems/scenic.md).
Пять требующих контекста сцен (оба дивана, радист, наблюдение за небом и удерживание двери) оставлены только
для ручного спавна; модели всех сценических акторов назначаются обычным спавнером и его хуками без подмены сценой.
GOAP-акторы в безнадёжном бою могут закрыть и удерживать открытую распашную дверь; полиция выбивает её ногой,
отбрасывая удерживающего временным регдоллом без дополнительного урона. Подъём сохраняет исходного актора/сущность
и здоровье, требует свободного места и возвращает прежнее боевое поведение/бегство. См. [мозги](systems/brains.md).
