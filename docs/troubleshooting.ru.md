# Решение проблем

| Симптом | Что проверить |
| --- | --- |
| Никто не появляется | Запустите `bgn_menu`, проверьте включение типов и ненулевые лимиты. Пройдитесь по карте и выполните `bgn_nav_info` на сервере. |
| Навигационных точек нет | Попробуйте `bgn_nav_generate around 1500`, затем `bgn_nav_info`. Это генератор точек аддона. Для всей карты есть `bgn_nav_generate`, остановка — `bgn_nav_generate stop`. См. [навигацию](systems/navigation.md). |
| Серверные настройки не видны или не меняются | Нужны права администратора; обычным игрокам эти разделы скрыты. Запустите `bgn_test_settings`: тест покажет, кем вас считает сервер. |
| Модуль не загружается | Проверьте путь `lua/background_npcs_core/custom_modules/config/`, префикс `sh_` и ошибки Lua в консоли. Перезапустите игру после создания нового каталога аддона. |
| Остались старые модели или реакции | `EditActor` объединяет таблицы. Для полной замены присвойте поле напрямую, как в [примерах](examples.md). |
| Нет машин | Нужны Decent Vehicle, установленные модели из списка `vehicles`, ненулевой `max_vehicle` и маршруты DV. Пешеходные точки не заменяют DV. |
| Нет озвучки | Проверьте `bgn_cl_voices 1`, язык голоса и наличие звуковых файлов. Режим `2` использует только старые звуки Half-Life 2. |
| Падает FPS | Начните с `bgn_crowd_density low`. Большое число призраков тоже нагружает клиент; см. [толпу](systems/ghost-crowd.md). |

Для отчёта об ошибке запустите [режим тестирования](systems/testing.md) (`bgn_test`) и приложите скопированный лог. Если этого мало, приложите название карты, режим игры, вывод `bgn_nav_info`, ошибки Lua и список шагов воспроизведения. Встроенные проверки: `bgn_selftest` на сервере, `bgn_selftest_cl` на клиенте; они не заменяют проверку поведения в игре.
