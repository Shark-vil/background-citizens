# GetMaxHealth

Общий метод: `actor:GetMaxHealth()` возвращает максимальное здоровье прикреплённой сущности, если она валидна и у неё есть функция `GetMaxHealth`. Иначе возвращает сохранённый максимум здоровья персонажа в машине либо `0`, если данных нет.

Как и у [Health](Health.md), метод текущей сущности имеет приоритет перед сохранёнными данными.
