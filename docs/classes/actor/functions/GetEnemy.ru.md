# GetEnemy

Окружение: **SHARED** (поддерживаемое использование).

```lua
actor:GetEnemy()
```

Возвращает выбранного живого врага либо NULL: прямого нападающего за последние 5 секунд, затем цель осады/группы, затем прежнюю допустимую боевую цель, затем ближайшего живого врага. GetNearEnemy остаётся запросом только по расстоянию. CLIENT использует полученные локальные данные; боевой выбор принадлежит SERVER.

Исходник: `lua/background_npcs_core/actor/components/sh_enemies.lua`.
