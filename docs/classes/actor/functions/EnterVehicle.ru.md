# EnterVehicle

Серверный метод: `actor:EnterVehicle(vehicle)` запрашивает посадку через 0,5 с. Требуются DV, механика `use_vehicle`, валидная машина и доступное разрешённое место. Перед посадкой доступ проверяется повторно; синхронного результата успеха нет.

Объект актора и UID сохраняются. Данные тела и снаряжения запоминаются, настоящий NPC/NextBot удаляется, актор привязывается к сущности водителя или пассажира DV. После успеха вызывается `BGN_OnEnterVehicle(actor, provider)`. В полицейские машины могут садиться только акторы полиции.
