# EnemiesRecalculate

Окружение: **SERVER** (поддерживаемое использование).

```lua
actor:EnemiesRecalculate()
```

Обновляет счётчики, наблюдает всех видимых известных врагов, удаляет мёртвых/забытых и назначает телу `GetEnemy()`; требует валидного тела. Обычный скрытый враг забывается спустя более 60 секунд от времени наблюдения/донесения. Записи управления преследованием в движковую память это время не продлевают. Исключения розыска и always-visible сохраняются. См. [боевую память](../../../systems/brains.md).

Исходник: `lua/background_npcs_core/actor/components/sh_enemies.lua`.
