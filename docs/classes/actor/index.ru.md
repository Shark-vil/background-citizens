# API актора

Актор — стабильная запись персонажа, связанная с движковой сущностью. Тело и мозг существуют на сервере; клиент получает данные для отображения.

- [Серверные методы](../../reference/server.md): создание, состояния, движение, бой, транспорт, речь, удаление.
- [Клиентские методы](../../reference/client.md): получение состояния и меню.
- [Общие методы](../../reference/shared.md): идентичность, здоровье, запросы состояния, врагов и целей, пространства имён.

Получение: `bgNPC.Actors.Get(entity)`, `GetByUid(uid)`, `GetFirst()`. Результат может быть nil; `actor:GetNPC()` проверяйте через `IsValid`.

Для новой сущности на сервере используйте `bgNPC.Actor.Create(npc, actor_type)`. [BGN_ACTOR:Instance](Instance.md) сохранён для совместимости. Не регистрируйте сущность дважды.

Посадка в DV сохраняет объект актора и UID, заменяет сущность визуальной моделью DV, а выход воссоздаёт сохранённое тело NPC/NextBot. После `BGN_ActorEntityChanged(actor, old, new)` заново получайте сущность. Приватные данные стороннего аддона требуют собственной интеграции. Для здоровья используйте `Health()` / `GetMaxHealth()`.

Сервис синхронизации с периодом 0,25 с отправляет изменения готовым игрокам в PVS: идентичность, поколение сущности, имя/группу состояния, врагов/цели, флаги анимации. Тело, мозг, полные данные состояния и изменения конфигурации целиком не копируются.

См. [примеры](../../examples.md) и [архитектуру](../../architecture.md).
