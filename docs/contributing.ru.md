# Сборка документации

Из корня репозитория выполните:

```text
python -m pip install -r requirements-docs.txt
python -m mkdocs serve
```

Откройте адрес из терминала. Для проверки перед коммитом:

```text
python -m mkdocs build --strict
```

Английские страницы имеют суффикс `.md`, русские — `.ru.md` рядом с оригиналом. Относительные ссылки пишите на `.md`: плагин сам выбирает язык. Для отсутствующего перевода используется английский текст. Сохраняйте старые пути страниц, чтобы не ломать внешние ссылки.

Workflow проверяет pull request и публикует сайт только при push в master. Нужны права GitHub Actions на запись и GitHub Pages с веткой gh-pages. Локальная сборка ничего не публикует.

Перед изменением публичного поведения прочитайте [правила документации для ИИ](ai.md) и [архитектуру](architecture.md). Обновляйте EN/RU и соответствующий справочник области вместе с кодом; сохраняйте URL страниц. Текущая база и границы релиза — в [истории](history.md).

## Локальная сборка для Workshop

В Windows установите Python 3.12+ и добавьте `glualint` в PATH. Один раз установите зависимость сборщика:

```text
python.exe -m pip install -r requirements-build.txt
```

Запустите `build.bat` из любой рабочей папки или двойным щелчком. Результат —
`build/background-citizens/`: папка аддона для Workshop с `addon.json`, лицензией,
минифицированной `lua/` и ссылками на игровые ресурсы. `build/` игнорируется Git.
Сборка ничего не публикует и не изменяет исходные Lua-файлы.

При первом запуске сборщик скачивает [glua-minify](https://github.com/TRIGONIM/glua-minify)
из коммита `4d19b690faf5e9cd3786d60609f6a02b6f645130` в `build/.tools/`, проверяет
SHA-256 и запускает через LuaJIT из Lupa. Следующие сборки используют проверенный
кеш без повторного скачивания. Адаптер исправляет проблемы парсера и областей
видимости: `goto`/метки, неявный `self` методов, локальные переменные repeat-циклов
и совпадения имён с глобальными переменными.

Каждый Lua-файл становится одной физической строкой: комментарии и лишние пробелы
удаляются, локальные переменные, функции и параметры получают короткие имена,
значения многострочных строк сохраняются через escape-последовательности. Имена
публичных методов, глобальных переменных, ключей таблиц, пути и структура файлов
SERVER/CLIENT/SHARED сохраняются. Файлы только с комментариями превращаются в
`return`, поскольку GMad не принимает пустые файлы.

Повторные прямые вызовы выбранных стандартных функций `math`, `string` и `table`
кешируются в локальных переменных файла. Вызовы через затенённые библиотеки не
меняются; обнаруженные записи в библиотеку, её алиасы или доступ к динамическому
окружению отключают соответствующее кеширование. **Кеширование предполагает, что
другие аддоны не подменяют эти стандартные функции после загрузки файла.** GMod API
и хуки остаются динамическими. Это минификация исходников с ограниченной
оптимизацией обращений, без обещания прироста FPS или оптимизации всей программы
как в C++. Стеки ошибок теряют подробные номера строк исходников.

Ресурсы подключаются ссылками из `materials/` (`vmt/vtf/png/jpg/jpeg`), `models/`
(`mdl/vvd/vtx/phy/ani`), `sound/` (`wav/mp3/ogg`) и `resource/`
(`properties/ttf`). Другие расширения и несовместимые с Workshop `*.sw.vtx`
исключаются. Если включены все файлы каталога, создаётся символическая ссылка на
каталог; иначе сборщик создаёт ссылки на отдельные включённые файлы. Когда
символические ссылки требуют дополнительных прав, Windows использует junction
для каталогов и жёсткие ссылки для файлов.
**Считайте связанные ресурсы доступными только для чтения: их правка меняет рабочие исходники.**
Из-за ссылок изменения ресурсов сразу видны в существующей сборке; перед упаковкой
пересоберите аддон, чтобы обновить Lua и выбор ресурсов. Папка сборки не является
автономной копией для переноса на другую машину.

Исходный и сгенерированный Lua должны пройти `glualint dump-ast`. Ошибка
преобразования или проверки синтаксиса сохраняет предыдущую успешную сборку.
Успешная пересборка заменяет только `build/background-citizens/`, удаляя устаревшие
сгенерированные файлы. Остальные файлы внутри `build/` сохраняются. Инструменты
разработки, документация и карантинные файлы не включаются. Для получения `.gma`
передайте полученную папку GMad по
[инструкции упаковки Workshop](https://wiki.facepunch.com/gmod/Workshop_Addon_Creation).

Регрессионные проверки сборщика:

```text
python.exe -m unittest discover -s tools -p test_build.py -v
```

Эти проверки выполняются вне игры и проверяют преобразования и работу с результатом;
перед публикацией проверьте собранный аддон в GMod.
