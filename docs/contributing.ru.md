# Сборка документации

Из корня репозитория выполните:

```text
python -m pip install -r requirements-docs.txt
python -m mkdocs serve
```

Откройте адрес из терминала. Для проверки перед коммитом:

```text
python -m mkdocs build --strict
```

Английские страницы имеют суффикс `.md`, русские — `.ru.md` рядом с оригиналом. Относительные ссылки пишите на `.md`: плагин сам выбирает язык. Для отсутствующего перевода используется английский текст. Сохраняйте старые пути страниц, чтобы не ломать внешние ссылки.

Workflow проверяет pull request и публикует сайт только при push в master. Нужны права GitHub Actions на запись и GitHub Pages с веткой gh-pages. Локальная сборка ничего не публикует.

Перед изменением публичного поведения прочитайте [правила документации для ИИ](ai.md) и [архитектуру](architecture.md). Обновляйте EN/RU и соответствующий справочник области вместе с кодом; сохраняйте URL страниц. Текущая база и границы релиза — в [истории](history.md).
