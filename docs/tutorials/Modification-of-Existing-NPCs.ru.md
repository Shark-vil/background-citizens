# Изменение существующих акторов

Создайте общий файл в `custom_modules/config`, как описано в [создании актора](Creating-Custom-NPCs.md). Для простых полей используйте:

```lua
bgNPC.cfg:EditActor('citizen', { health = 80, random_skin = true })
```

`EditActor` объединяет данные через `table.Merge`, включая вложенные таблицы. Для замены списков моделей, команд или реакций целиком присвойте новую таблицу:

```lua
-- lua/background_npcs_core/custom_modules/config/sh_mytown_citizens.lua
local citizen = bgNPC.cfg.actors['citizen']
citizen.health = 80
citizen.default_models = false
citizen.models = { 'models/Humans/Group01/male_07.mdl' }
citizen.at_random = { walk = 80, idle = 20 }
```

Не используйте `SetActor` для частичного изменения: он заменяет всю конфигурацию. Перезагрузите карту для проверки. Стандартные конфигурации находятся в `lua/background_npcs_core/config/actors/`, например `sh_citizen.lua`.

## Предметы в руках

`carry_items` задаёт общий шанс для нового невооружённого актора. У обычных жителей по умолчанию 5%;
полиция, медики, бандиты, воры и таксисты переопределяют унаследованное поле значением `false`.

```lua
bgNPC.cfg.actors.citizen.carry_items = {
    chance = 5,
    items = { 'ration', 'suitcase', 'newspaper' },
    drop_lifetime = 30,
}
-- carry_items = false отключает эту возможность для пользовательского типа.
```

У типов с такой таблицей появляется чекбокс **Спавнить с предметами в руках** в обоих меню акторов
(`bgn_carry_items_<тип>`, серверная настройка, по умолчанию `1`). Он влияет на обычных новых акторов. Оба вида призраков и акторы, появившиеся из серверных призраков, всегда без предметов.
NextBot нужны анимации ожидания/ходьбы для еды и газет; кейсу нужна только кость правой кисти. `newspaper` использует двуручную
позу пайка: сам паёк скрыт, штатная газета HL2 подогнана между кистями. Модели/ассеты не подменяются. Нижний край газеты следует за пальцами, текст ориентирован прямо, верх отклонён от лица на 15 градусов. Кейс обычного NPC висит вертикально на хвате правого указательного пальца, в том числе при штатной ходьбе.
Обычные HL2 NPC поддерживают только `suitcase`: клиентский `briefcase001a` следует кости правой руки без
выдачи оружия-предмета и без переопределения ходьбы/активности. Остальные предметы исключаются до выбора.
Паёк/газета убираются при занятии рук или беге NextBot и могут вернуться после действия. На обоих типах тела клиентский кейс остаётся прикреплённым во время мирных действий и бега, без оружия-предмета и специальных анимаций багажа. Он удаляется при состояниях групп danger, guarded, assault, при retreat, смерти или удалении актора и никогда не становится брошенным объектом. Клиентские предметы настоящих акторов используют существующие PVS-снимки и скрываются вместе с родителем.

Администраторы могут использовать **Background NPCs → Отладка предметов в руках** (`bgn_carry_debug`): выберите кейс, еду или газету и нажмите ЛКМ на живого безоружного актора вне машины в спокойном состоянии. Шанс спавна и его чекбокс игнорируются; поддержка предмета телом/моделью проверяется. ПКМ убирает предмет. Выдача включает ходьбу и отменяет последующий автоматический выбор предмета.

Предметы исключены из `actor:GetActiveWeapon()` / `HasActiveWeapon()` и проверок угрозы; они не заменяют
назначенное актору боевое оружие. При этом сама движковая сущность может возвращать своё оружие-предмет.
