# Навигация

Сервер выбирает один провайдер: сохранённый граф аддона (`data/background_npcs/graph/<map>.dat`), затем NavMesh карты, затем HL2 nodegraph (`maps/graphs/<map>.ain`). Если данных нет, используется пустой собственный граф с генерацией во время работы. Старые маршруты автоматически конвертируются при загрузке. Аддон не запускает движковую генерацию NavMesh.

| Команда | Назначение |
| --- | --- |
| `bgn_nav_info` | Провайдер и число точек |
| `bgn_nav_provider auto` | Автоматический выбор; также доступны `navmesh`, `nodegraph`, `custom` |
| `bgn_nav_reload` | Перезагрузить данные |
| `bgn_nav_generate around 1500` | Сгенерировать точки вокруг игрока |
| `bgn_nav_generate` | Генерация по всей карте от точек появления и игроков |
| `bgn_nav_generate stop` | Остановить генерацию |
| `bgn_compile` | Упаковать маршруты, сиденья и точки DV в Lua для распространения |
| `bgn_save_map` | Сохранить активный граф в дубликаты игрока |

Кнопка «Сохранить для Мастерской» (`bgn_compile`) сохраняет пакет маршрутов также на компьютер
вызвавшего администратора: `garrysmod/data/background_npcs/compile/bgn_compile_<map>.txt`.
Окно результата показывает путь и дальнейшие действия: переименовать файл в `.lua` и положить
в `lua/autorun/server` публикуемого аддона. В пакет попадает текущий граф, включая загруженный из дубликата.

Команды выполняются на сервере с правами администратора. Лимит генератора `bgn_nav_generator_max_nodes` — 15000. Инструмент Point editor создаёт, связывает и удаляет точки собственного графа; сохраняйте маршрут кнопкой панели. Path finder показывает путь между точками.

Поддерживаются безверсионные сетки и форматы 1.0–1.2 из `data/citizens_points/` и
`data/background_npcs/nodes/` (`.dat` и `.json`). Исходные файлы при загрузке не изменяются.
При автоматической загрузке старая сетка сразу сохраняется в актуальном формате в
`data/background_npcs/graph/<map>.dat`. Исправный новый граф имеет приоритет; повреждённый восстанавливается
из старой сетки, если она доступна.
Большие графы сохраняются без лимита JSON на 15 000 элементов и без округления координат.
В новом файле записывается число точек и связей; несовпадение при чтении считается повреждением.
Автодополнение `bgn_convert_legacy_nodes` предлагает карты со старой сеткой, для которых ещё нет
нового графа на сервере. Без аргумента конвертируется текущая карта.

Для загрузки маршрута выберите его на вкладке «Дубликаты» спавнменю. Старые дубликаты `BGN_NODES`
от SLibrary тоже поддерживаются, сама библиотека не нужна. Маршрут применяется на сервере и открывается
в редакторе точек; чтобы оставить его после перезапуска карты, нажмите сохранение маршрута в редакторе.
Сохранённый файл не перезаписывается при выборе дубликата. Эти действия доступны администраторам;
новые дубликаты можно загрузить только на той карте, для которой они сохранены.

## Двери и машины

На сервере `bgNPC.Util.CanActorOpenDoor` также запрещает обычное открытие двери, занятой состоянием `hold_door`,
даже если включено открытие запертых дверей. В безнадёжном бою GOAP может закрыть и удерживать открытую дверь;
полиция может выбить эту временную блокировку. См. [удерживание и выбивание дверей](brains.md).

`bgn_npc_open_doors 1` разрешает открывать двери. Запертые двери по умолчанию запрещены (`bgn_npc_open_locked_doors 0`); при включении актор отпирает дверь и после закрытия через 10 секунд запирает её снова. Настройки находятся в общем разделе меню.

Полицейские машины при погоне и скорая на вызове используют маршруты Decent Vehicle, сирену и игнорируют светофоры. Пешеходный граф не заменяет автомобильный.

## API сервера

```lua
local info = bgNPC.Nav.GetInfo() -- provider, points, links, source
print(info.provider, info.points)
local points = bgNPC.Points.GetInRadius(Vector(0, 0, 0), 1000)
for _, point in ipairs(points) do
    print(point:GetPos())
end
```

События: `BGN_NavProviderChanged(provider)`, `BGN_NavGeneratorFinished(graph, added_count)` на сервере; `BGN_NavEditorGraphLoaded(graph)` на клиенте.

`Points.GetRandom` возвращает Vector либо nil, если подходящих точек нет; пустой запрос радиуса графа
не переходит к выбору в другой части карты. NavMesh выбирает из загруженного списка областей,
а не из предполагаемого непрерывного диапазона ID. После внешнего изменения сетки выполните `bgn_nav_reload`.
