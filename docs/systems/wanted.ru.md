# Розыск и нарушители

Исходники: `systems/wanted/`, `systems/sv_offender.lua`, `config/states/sh_wanted.lua`. Розыском и реакциями управляет сервер; клиент получает записи и рисует HUD/подсветку.

| Серверная cvar | По умолчанию | Назначение |
|---|---|---|
| `bgn_enable_wanted_mode` | `1` | Включает розыск; изменение очищает существующие записи. |
| `bgn_wanted_time` | `30` | Базовая длительность розыска, секунды. |
| `bgn_wanted_level` | `1` | Разрешает рост уровня (до 5). |
| `bgn_wanted_police_instantly` | `1` | Включает обработку немедленной реакции полиции. |
| `bgn_wanted_impunity_limit` | `5` | Порог безнаказанности для обработчиков розыска. |
| `bgn_wanted_impunity_reduction_period` | `10` | Секунды между уменьшениями безнаказанности. |

Убийства, свидетели, вызовы полиции и отказ от ареста участвуют в розыске. Игнорируемые/арестованные игроки и акторы-медики исключаются из новых записей. При смене тела DV идентичность розыска сохраняется. Разыскиваемый актор, которого игроки не видят 15 секунд, снимается с розыска; это отдельно от истечения розыска игрока и удаления популяции.

Житель, убивший другого жителя либо повредивший полицейскую машину тараном, становится нарушителем (на таран машиной под управлением актёра полиция реагирует лишь с шансом 10% за удар; иначе удар игнорируется и не ранит полицейских, `modules/dv/sv_car_damage_reaction.lua`): в его собственной копии конфига residents заменяется на offenders. Окончание розыска не восстанавливает команду. Замеченное преступление может также включить розыск, если режим включён. Реакции — [мозги](brains.md), сдача/отказ — [арест](arrest.md).

## Интеграция

Получайте `local wanted = bgNPC.Modules.Get('wanted')` после загрузки систем; до этого либо в другом окружении возможен nil. Запросы: `wanted:HasWanted(entity)`, `GetWanted(entity)`, `GetAllWanted()`. Изменяйте на SERVER через `AddWanted(entity, time)`, `RemoveWanted(entity)`; повторное добавление не сбрасывает и не продлевает таймер. Возвращённая запись поддерживает `UpdateWanted(time)`, `SetLevel(level)`, `LevelUp()`, `LevelDown()`; неположительный SetLevel снимает розыск, значения выше 5 ограничиваются.

Хуки: `BGN_AddWantedTarget`, `BGN_RemoveWantedTarget`, `BGN_WantedLevelUp`, `BGN_WantedLevelDown`. При `BGN_PlayerReady` сервер передаёт уже действующие записи. Клиентские настройки HUD не отключают серверную систему.
