# Разговоры, взгляды и драки

`bgn_disable_dialogues 1` отключает разговоры. Спокойный актор выбирает `dialogue` по весу `at_random`, ищет подходящих участников в пределах 400 единиц, подходит и произносит реплики с жестами. Опасность или смена состояния одного участника завершает разговор всех.

Сценарии находятся в `config/states/sh_conversations.lua`, фразы — в `bgNPC.cfg.replics['conv_<id>']` каждого языка. Число фраз должно совпадать с числом строк сценария.

## Пример своего разговора

Добавьте в общий файл `custom_modules/config/sh_mytown_talk.lua`:

```lua
bgNPC.cfg.replics['conv_mytown'] = {
    'Доброе утро!',
    'Привет, как дела?',
    'Всё спокойно.',
}
table.insert(bgNPC.cfg.conversations, {
    id = 'mytown',
    roles = { 'citizen', 'citizen' },
    lines = { { 1 }, { 2, 'wave' }, { 1 } },
    chance = 10,
})
```

Пример задаёт один русский текст для всех; для полноценной локализации добавьте таблицу реплик в каждый язык. Озвучка не создаётся автоматически. Проверка `conversations.scripts` в `bgn_selftest` проверяет соответствие строк.

Поле `final`: без значения — разойтись; `fight` — кулачная драка; `attack` — вторая роль атакует первую; `flee` — вторая роль убегает; `run_off` — убегает первая роль.

## Реакция на игрока

Игрок, смотрящий на обычный разговор с расстояния до 250 единиц две секунды, может его прервать. Долгий взгляд на стоящего актора вызывает обращение через 3 секунды, предупреждение через 7 и возможную драку через 11. Полиция только предупреждает.

Кулачная драка заканчивается при низком здоровье, через 45 секунд или при удалении на 800 единиц. Игрока не забивают ниже 15 HP. Полицейские с включённым арестом задерживают обоих участников.
