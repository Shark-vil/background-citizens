# Меню настроек

**Поведение → ИИ** и **Classic → Расширения** содержат чекбокс **Реакция на оружие в руках**
(`bgn_react_to_lethal_weapon`, SERVER/администратор, по умолчанию `0`). Обучение продолжается и при
выключенной настройке; см. [обнаружение, реакции и хранение классов оружия](brains.md#lethal-weapons).
Там же чекбокс **Паника и поиск угрозы** (`bgn_threat_search`, SERVER/администратор, по умолчанию `0`);
см. [панику и поиск угрозы](brains.md#threat-search).

Откройте `bgn_menu`, значок Background NPCs в меню C или Spawn menu → Options → Background NPCs → Open settings. Ctrl+F ищет по подписям, подсказкам и именам cvar; Esc очищает поиск.

Блок **Быстрые настройки** (выбор режима и пошаговая настройка) лежит вверху страницы «Основное», пока его не закрыли крестиком (`bgn_menu_quick_hidden`, клиентская настройка), и всегда лежит вверху страницы «Инструменты».

Серверные разделы видны администраторам. «Мои настройки» действуют на текущем компьютере. Светлая и тёмная тема переключаются кнопкой солнца/луны или `bgn_menu_dark`; звуки — `bgn_menu_sounds`.

**Инструменты → Тестирование** запускает [режим тестирования](testing.md): проверки спавна, машин, состояний и настроек с копируемым логом.

**Модули** перечисляет включаемые модули: Розыск, Арест, Сценические NPC, Decent Vehicle и поддерживаемые аддоны. Переключатель модуля виден всем и заблокирован для игрока без прав администратора. Шестерёнка открывает страницу самого модуля (она открывается только отсюда, в боковом списке её нет; поиск находит её строки) с разделами **Сервер** (администраторам) и **Только у вас** (настройки этого компьютера, например HUD и обводка розыска). Шестерёнка есть, только если у игрока есть что показать: любая серверная строка для администратора, клиентская строка для всех; у Decent Vehicle серверные строки есть, только пока загружен Decent Vehicle (`DecentVehicleDestination`).
**Модули → Сценические NPC (шестерёнка)** содержит чекбокс для каждой сцены, доступной автоспавну (`bgn_scenic_<id>`).
В разделе **Акторы** число машин типа отмечено синей меткой **Decent Vehicle** (только пока загружен Decent Vehicle), а чекбокс **Спавнить с предметами в руках** (`bgn_carry_items_<тип>`) появляется только
у типов с таблицей `carry_items` в конфиге. Оба переключателя есть и в классическом меню; они действуют
на будущий спавн, включая предметы призраков.

В Spawnmenu **Options → Background NPCs → Отладка** собраны отладочные отображения, пути NPC, WH акторов,
инспектор состояний/решений, визуализация видимости и камера от лица актора. См. [управление отладкой](testing.md#spawnmenu-debug-page).

Инструменты разделены на **Background NPCs: Редактор** (точки, зоны спавна, сиденья) и **Background NPCs: Отладка** (инспектор, навигация, перемещение, сцены, предметы). Страница отладки и Tool инспектора используют общий выбор UID, режимы отображения, дальности/фильтры и заморозку снимка.

## Спавн и удаление акторов

Раздел «Спавн» содержит настройки пешеходов; радиус видимости транспорта находится в **Модули → Decent Vehicle (шестерёнка)**. Серверные значения по умолчанию:

| Cvar | Значение | Назначение |
| --- | --- | --- |
| `bgn_spawn_period` | 0 | Пауза в секундах между проходами спавнера. |
| `bgn_actors_max_teleports` | 10 | Максимальное число переносов акторов в секунду. |
| `bgn_actors_teleporter` | 1 | Переносить подходящих невидимых акторов вместо удаления. |
| `bgn_spawn_radius` | 3000 | Радиус поиска точек появления вокруг игроков. |
| `bgn_spawn_block_radius` | 600 | Запрет появления пешеходов ближе этого расстояния к любому игроку. |
| `bgn_spawn_no_visibility_trace` | 0 | Не трассировать укрытия пешеходов: точка появления или телепортации в поле зрения любого игрока отклоняется даже за препятствием. |
| `bgn_spawn_radius_visibility` | 2000 | Радиус видимости игроков. Используется только [розыском](wanted.md): разыскиваемый NPC/актор (не игрок) снимается с розыска через 15 с вне поля зрения всех игроков либо дальше половины этого радиуса; препятствия не учитываются. |
| `bgn_vehicle_spawn_visibility_radius` | 2000 | В этом радиусе в направлении взгляда машина появляется, только если весь кузов (сетка точек по габаритам) скрыт укрытием; действует только на транспорт. |
| `bgn_actor_unseen_time` | 30 | Время без видимости у всех игроков до удаления или телепортации подходящего актора; `0` разрешает обработку сразу вне видимости. |
| `bgn_vehicle_cleanup_time` | 120 | Таймер удаления невидимой машины BGN без водителя либо без перемещения дальше 128 единиц от опорной позиции; `0` отключает эту дополнительную очистку. |

Спавн и телепортация пешехода проверяют видимость ног, груди и головы, спавн транспорта — сетку точек по кузову. Точка в поле зрения игрока считается укрытой, только если препятствие останавливает луч взгляда не ближе 40 единиц до неё; собственная машина игрока укрытием не считается. За пределами поля зрения точки вне запрещённого радиуса остаются доступными. Проверки кандидата не прерываются посередине. Разговор, арест, воскрешение, сценическая работа, салон машины и заблокированное состояние защищают от обычного удаления или телепортации. Таймер невидимости действует и при превышении лимита; отключение аддона или типа обрабатывается отдельно. Очистка транспорта учитывает частично видимый кузов и занятые игроками места.

## Язык

`bgn_cl_ui_language`: `auto`, `english`, `russian`. Язык голоса выбирается отдельно через `bgn_cl_voice_language`; см. [голоса](voices.md). Выбор языка сайта не влияет на игру.
Синхронизация языка передаёт на SERVER только код (`bgn_cl_language`): серверные отчёты Tools тоже используют выбранный язык мода.

## Первый запуск

Мастер настройки сам открывается один раз на первой карте (через 5 секунд после загрузки, пока `bgn_mode_chosen` равен 0) со всеми шагами, как `bgn_wizard all`, и только владельцу игры (одиночная игра или хост листен-сервера); игрок, зашедший на сервер, его не видит, мастер доступен из меню и консоли. Отдельного окна выбора режима нет: шаг *body* выбирает между обычными NPC Half-Life 2 (работают реплейсеры и моды на стандартных NPC, нагрузка минимальна) и NextBot (толпа, GOAP, постановочные сцены; реплейсеры на них не действуют, нагрузка выше). Клиентская настройка `bgn_mode` (по умолчанию `classic`) выставляется только командой `bgn_classic` и определяет, какие `modern`-шаги скрывает обычный `bgn_wizard`. Размер интерфейса задаёт `bgn_cl_ui_scale` (0.75–2). Однократная миграция (`bgn_settings_rev`): призраки выключаются, `auto` у тела и мозга становится `npc` / `fsm`; клиент с `bgn_mode new` выбор сохраняет. Серверная часть пресета применяется только администратором.

| Команда | Действие |
| --- | --- |
| `bgn_wizard` | Мастер без расширенных шагов |
| `bgn_wizard all` | Все шаги, включая расширенные |
| `bgn_mode_chosen 0` | Повторить первый запуск на следующей карте |

Изменения мастера применяются сразу. `bgn_crowd_density low|medium|high|ultra` задаёт общий лимит акторов и призраков: 25/0, 35/40, 60/80, 100/150. Админ меняет серверные лимиты и своих призраков; игрок — только своих призраков, и только пока сервер не ведёт фоновую толпу (иначе выбор заблокирован с пояснением).

## Классические страницы в меню спавна

Меню спавна → Опции → Background NPCs хранит и страницы старых версий (Общее, Актёры, Спавн, Розыск, Арест, Расширения, Оптимизация, Аддоны, Клиент, Мастерская) для тех, кто привык. Они генерируются из таблицы `PAGES` в `ui/settings/cl_classic_settings.lua`: элемент — `{ тип, cvar_или_команда, ключ_фразы, ... }` (`check`, `slider`, `button`, `actors`), страница с `admin = true` неадминам показывает пояснение. Тексты берутся из `resource/localization/<язык>/bgn_*.properties` (английский и русский, либо язык, выбранный в окне настроек). Элемент, чьего cvar или команды больше нет, пропускается. Страница *Settings* открывает новое окно. Админская команда `bgn_classic` / чат `!bgn_classic` применяет классический пресет (`bgNPC.ClassicPreset` в `systems/sh_classic_mode.lua`, тот же, что у режима *Classic*).

## Своя страница

Клиентский файл `custom_modules/postload/cl_mytown_menu.lua`:

```lua
CreateClientConVar('mytown_hints', '1', true, false)
bgNPC.Menu.AddPage('mytown', {
    title = { en = 'My town', ru = 'Мой город' },
    order = 1300,
    build = function(page)
        page:Section('Подсказки')
        page:Toggle('mytown_hints', 'Показывать подсказки')
    end,
})
```

Другие элементы: `page:Slider`, `Choice`, `Button`, `Color`, `Note`. Поиск вызывает построение всех страниц; учитывайте `page.filter` для дорогих операций.

## Уведомления об изменении настроек

Каждое изменение настройки показывает уведомление в правом нижнем углу поверх меню: **синяя** плашка *СЕРВЕР*
(`#03a9f4`) — серверная настройка (в том числе изменённая кнопкой «Исправить» режима тестирования), её видят все
игроки после того, как сервер её применил; **янтарная** плашка *КЛИЕНТ* (`#dea909`) — клиентская `bgn_cl_*`, её видит
только свой игрок. На плашке имя и `было > стало`; каждое изменение получает плашку (без лимита, стопка растёт вверх), плашка живёт 6 секунд, уходят они по одной в порядке
появления; каждое переключение даёт новую плашку, а повторно изменённый ползунок обновляет свою плашку на месте, а не добавляет новую, а лимиты, которые мод сам
переписывает после `bgn_max_npc`, не объявляются. Если копия у админа устарела, сервер тихо присылает реальное значение.

Уведомления автономны (`core/sh_notice.lua`): файл подключается первым, имеет свою сетевую строку, проверку языка и
отрисовку, а ошибка рисования перехватывается, поэтому сбой любого последующего скрипта их не отключит. Для своего
квара вызовите `bgNPC.Notice.Watch(name)` (серверный квар видят все, клиентский — только свой игрок).
