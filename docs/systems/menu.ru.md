# Меню настроек

Откройте `bgn_menu`, значок Background NPCs в меню C или Spawn menu → Options → Background NPCs → Open settings. Ctrl+F ищет по подписям, подсказкам и именам cvar; Esc очищает поиск.

Серверные разделы видны администраторам. «Мои настройки» действуют на текущем компьютере. Светлая и тёмная тема переключаются кнопкой солнца/луны или `bgn_menu_dark`; звуки — `bgn_menu_sounds`.

**Инструменты → Тестирование** запускает [режим тестирования](testing.md): проверки спавна, машин, состояний и настроек с копируемым логом.

## Язык

`bgn_cl_ui_language`: `auto`, `english`, `russian`. Язык голоса выбирается отдельно через `bgn_cl_voice_language`; см. [голоса](voices.md). Выбор языка сайта не влияет на игру.

## Первый запуск

Окна сами показываются только владельцу игры (одиночная игра или хост листен-сервера); игрок, зашедший на сервер, их не видит, они доступны из меню и консоли. Сначала появляется выбор Classic / New (равноправные режимы, окно лишь объясняет разницу; сменить можно в любой момент), затем мастер. Classic задаёт тело `npc`, мозг `fsm`, отключает призраков и оставляет звуки Half-Life 2. New задаёт тело `nextbot`, мозг `auto`, включает призраков и озвучку. Размер интерфейса задаёт `bgn_cl_ui_scale` (0.75–2). Однократная миграция (`bgn_settings_rev`): призраки выключаются, `auto` у тела и мозга становится `npc` / `fsm`; выбор New сохраняется. Серверная часть пресета применяется только администратором.

| Команда | Действие |
| --- | --- |
| `bgn_mode_welcome` | Открыть выбор режима |
| `bgn_wizard` | Мастер текущего режима |
| `bgn_wizard all` | Все шаги, включая расширенные |
| `bgn_mode_chosen 0` | Повторить первый запуск на следующей карте |

Изменения мастера применяются сразу. `bgn_crowd_density low|medium|high|ultra` задаёт общий лимит акторов и призраков: 25/0, 35/40, 60/80, 100/150. Админ меняет серверные лимиты и своих призраков; игрок — только своих призраков, и только пока сервер не ведёт фоновую толпу (иначе выбор заблокирован с пояснением).

## Классические страницы в меню спавна

Меню спавна → Опции → Background NPCs хранит и страницы старых версий (Общее, Актёры, Спавн, Розыск, Арест, Расширения, Оптимизация, Аддоны, Клиент, Мастерская) для тех, кто привык. Они генерируются из таблицы `PAGES` в `ui/settings/cl_classic_settings.lua`: элемент — `{ тип, cvar_или_команда, ключ_фразы, ... }` (`check`, `slider`, `button`, `actors`), страница с `admin = true` неадминам показывает пояснение. Тексты берутся из `resource/localization/<язык>/bgn_*.properties` (английский и русский, либо язык, выбранный в окне настроек). Элемент, чьего cvar или команды больше нет, пропускается. Страница *Settings* открывает новое окно. Админская команда `bgn_classic` / чат `!bgn_classic` применяет классический пресет (`bgNPC.ClassicPreset` в `systems/sh_classic_mode.lua`, тот же, что у режима *Classic*).

## Своя страница

Клиентский файл `custom_modules/postload/cl_mytown_menu.lua`:

```lua
CreateClientConVar('mytown_hints', '1', true, false)
bgNPC.Menu.AddPage('mytown', {
    title = { en = 'My town', ru = 'Мой город' },
    order = 1300,
    build = function(page)
        page:Section('Подсказки')
        page:Toggle('mytown_hints', 'Показывать подсказки')
    end,
})
```

Другие элементы: `page:Slider`, `Choice`, `Button`, `Color`, `Note`. Поиск вызывает построение всех страниц; учитывайте `page.filter` для дорогих операций.

## Уведомления об изменении настроек

Каждое изменение настройки показывает уведомление в правом нижнем углу поверх меню: **синяя** плашка *СЕРВЕР*
(`#03a9f4`) — серверная настройка (в том числе изменённая кнопкой «Исправить» режима тестирования), её видят все
игроки после того, как сервер её применил; **янтарная** плашка *КЛИЕНТ* (`#dea909`) — клиентская `bgn_cl_*`, её видит
только свой игрок. На плашке имя и `было > стало`; ползунок обновляет одну плашку, а лимиты, которые мод сам
переписывает после `bgn_max_npc`, не объявляются. Если копия у админа устарела, сервер тихо присылает реальное значение.

Уведомления автономны (`core/sh_notice.lua`): файл подключается первым, имеет свою сетевую строку, проверку языка и
отрисовку, а ошибка рисования перехватывается, поэтому сбой любого последующего скрипта их не отключит. Для своего
квара вызовите `bgNPC.Notice.Watch(name)` (серверный квар видят все, клиентский — только свой игрок).
